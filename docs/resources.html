Metadata source

Country of origin, isolation source, host species, and collection year are extracted from NCBI BioSample records via the NCBI Datasets command-line tool. Field names (geo_loc_name, isolation_source, host, collection_date) are parsed from the standard BioSample attribute list and stored alongside the accession in a metadata table.

Genome accessions and assembly metadata are retrieved from NCBI Assembly under taxonomy IDs appropriate for each species.
