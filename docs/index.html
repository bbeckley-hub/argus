The bottleneck

Finding the right genomes should not be this hard.

The exponential growth of publicly available pathogen genomes has created an unprecedented opportunity for genomic epidemiology. Yet a persistent bottleneck remains: retrieving a defined subset of genomes that match specific genotypic or epidemiological criteria.

Old way Hours of scripting before science

  • Download static compressed TSVs from five different sources
  • Manually join tables by accession — mismatch errors guaranteed
  • Write Python scripts to filter genotype and metadata separately
  • Debug the pipeline when a column name changes
  • Query again from scratch for each new criterion
  • Duplicate data across tools and pipelines

ARGUS way Minutes from query to accession list

  • Open one interactive browser page — no install, no login
  • Stack filters across genotype, geography, and metadata in one query
  • Watch matching counts update live as you narrow the search
  • Export a clean plain-text accession list with one click
  • Feed directly into NCBI Datasets for genome retrieval
  • Every annotation, every metadata field — one architecture
The solution

Four steps from query to genome.

Every ARGUS platform is built around the same workflow — the actual downstream deliverable, a clean accession list, sits at the centre of the interface.

1

Filter

Stack filters across genotype, geography, and metadata. Sequence type, resistance gene, country, source, year — all in one place.

2

Verify

See live counts, distribution charts, and lineage context before you download anything. Confirm the query returns what you need.

3

Export

One click downloads a plain-text accession list. No scripting. No API keys. No CSV wrangling. Just one ID per line.

4

Download

Feed the list to NCBI Datasets and retrieve the underlying assemblies. Every platform is designed around this final step.
