# ARGUS: Antimicrobial Resistance Genomic Unified Surveillance

Welcome to ARGUS, a unified platform for species-specific genomic surveillance of the WHO priority ESKAPE pathogens. 

ARGUS serves as the umbrella architecture for a suite of independent, citable databases. It uses a zero-cost, serverless architecture designed for longevity and resource-limited settings.

## Current Pathogens
*   **SAURUS**: *Staphylococcus aureus* Unified Resource for Universal Surveillance (Live: [saurus-db.org](https://saurus-db.org))

## Architecture
All ARGUS databases are generated by self-contained Python scripts and hosted as static sites via GitHub Pages. No relational databases, no server costs, no API rate limits.
