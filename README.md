## Overview

**ARGUS** is a unified, species-specific genomic surveillance platform designed to address a persistent bottleneck in genomic epidemiology: the retrieval of genome accessions matching highly specific genotypic and epidemiological criteria. 

While domain-scale archives (like AllTheBacteria) and bulk annotation databases (like Shelenkov et al.) provide uniformly processed data, extracting a defined subset—such as *all MRSA ST5 isolates carrying SCCmec II and capsule type 5 from bloodstream infections in the USA*—still requires writing custom scripts or navigating multiple standalone tools. ARGUS solves this by providing an interactive, accession-first retrieval layer for the WHO priority ESKAPE pathogens.

## The ARGUS Architecture

ARGUS databases are built on a **zero-cost, serverless architecture** specifically designed for longevity and resource-limited settings. 
*   **Static-Site Generation:** All pages are generated by self-contained Python scripts and compiled into static HTML/CSS/JS.
*   **Zero Backend Maintenance:** Hosted entirely on GitHub Pages over HTTPS. No relational databases, no server costs, no API rate limits, and no data decay.
*   **Accession-First Export:** One-click export of clean accession lists, ready for direct ingestion by the NCBI `datasets` CLI or downstream pipelines.

## Roadmap (Upcoming ESKAPE Pathogens)

ARGUS leverages species-optimized pipelines already developed by our group (such as EcoliTyper and AcinetoScope) to expand across the ESKAPE pathogens. The roadmap includes:

- [ ] *Escherichia coli* (via EcoliTyper)
- [ ] *Acinetobacter baumannii* (via AcinetoScope)
- [ ] *Klebsiella pneumoniae*
- [ ] *Pseudomonas aeruginosa*
- [ ] *Enterococcus faecium*

## Funding and Sustainability

**ARGUS is developed entirely without external grant funding.** 

This project is a grassroots initiative developed in a resource-limited setting to demonstrate that high-impact, world-class genomic surveillance can be achieved through resourceful engineering. 

*   **Infrastructure Support:** The permanent registration of our web domains (`argus-db.org` and `saurus-db.org`) and ongoing maintenance costs are generously supported by our collaborators and co-authors.
*   **Computational Support:** Large-scale genomic processing is performed on the **ZUPUTO High-Performance Computing (HPC) cluster** at the University of Ghana.
